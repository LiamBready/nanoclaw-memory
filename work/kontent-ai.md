# Kontent.ai / Kentico

Past client, roughly 2018-2023 — his largest body of GitHub work by repo
count (57 own repos, nearly half of everything he's built publicly). Near-
total activity gap in 2024 marks the transition away from this work toward
CKEditor.

## What he built

SDKs, custom elements, and starter/boilerplate integrations across the
Jamstack ecosystem: Gatsby, Next.js, Gridsome, Svelte, Vue custom elements,
a Java/Kotlin/Spring/Android SDK monorepo, .NET migration tooling.

Highlights:
- [kontent-template-gatsby-landing-page-photon](https://github.com/Simply007/kontent-template-gatsby-landing-page-photon) - his most-starred/forked repo (12 stars, 14 forks)
- [kontent-sample-app-gatsby-intranet](https://github.com/Simply007/kontent-sample-app-gatsby-intranet) - Material-design intranet admin UI on Gatsby
- [kontent-environments-comparer](https://github.com/Simply007/kontent-environments-comparer) - Vue tool to diff two Kontent.ai environments
- [kontent-migrations-boilerplate-net](https://github.com/Simply007/kontent-migrations-boilerplate-net) - .NET scripted content migrations
